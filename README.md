# SupportDesk API

Production-oriented Enterprise Customer Support and Ticket Management Platform built with Python, FastAPI, PostgreSQL, Redis, and Docker.

## Overview

SupportDesk is a multi-tenant customer support platform designed to help organizations manage customer support tickets, agent assignments, conversations, SLA deadlines, and support operations efficiently.

The project focuses on real-world backend engineering practices, maintainable architecture, database performance, security, testing, and scalability.

## Technology Stack

- Python 3.13
- FastAPI
- PostgreSQL
- SQLAlchemy 2.0
- Alembic
- Redis
- Celery
- Pytest
- Locust
- Docker
- Nginx
- GitHub Actions

## Core Features

- Multi-organization support
- Role-based access control (RBAC)
- Ticket management and assignment
- Customer-agent conversations
- SLA monitoring and escalation
- Notifications
- Reporting and analytics
- Audit logging

## Architecture

The application will follow a Modular Monolith architecture with layered components:

- Router
- Service
- Repository
- Database Models
- Schemas
- Permissions
